# Marian College Lab Cycle 2 - Object Oriented Programming in Java

## Purpose
This repository contains a collection of standalone Java programs created for an academic lab assignment. The programs demonstrate core Object-Oriented Programming (OOP) principles and basic algorithmic concepts in Java.

## Technology Used
* **Programming Language:** Java
* **IDE:** IntelliJ IDEA

## Project Structure
The repository is structured as a simple Java project where all source code resides in the `src/` directory. Each `.java` file contains its own `main` method and acts as an independent executable program.

## Java Programs and Concepts Demonstrated

* **Basic & Algorithmic Programs**
  * `Main.java` - Basic loops.
  * `CELSIUS_TO_FARENHEIT.java` - Static methods and mathematical calculations.
  * `FACTORIAL.java` - Recursion.
  * `FIBONACCI.java` - Recursion.
  * `SUM_OF_NATURAL_NUMS.java` - Recursion.
  * `FINAL.java` - Constant variables using the `final` keyword.

* **Classes and Objects**
  * `EMPLOYEE.java` - Basic class attributes and methods.
  * `CIRCLES.java` - Mathematical operations within a class.
  * `RECTANGLE.java` - Class state and area calculation.
  * `LARGE_BOX.java` - Comparing object properties.

* **Constructors & Keyword Usage**
  * `STUDENT_CONSTRUCTOR_DEFAULT.java` - Default constructors.
  * `THISEXAMPLE.java` - Using the `this` keyword.
  * `THIS_COSTRUCTOR.java` - Constructor chaining using `this()`.

* **Method Overloading**
  * `AREA_OVERLOADING.java` - Overloading based on parameter count.
  * `METHOD_OVER_LOADING.java` - Overloading based on parameter types.

* **Object Interaction & Lifecycle**
  * `PASSING_OBJECT.java` - Passing objects as arguments.
  * `RETURN_METHOD.java` - Returning objects from methods.
  * `COUNTING_OBJECTS.java` - Using static variables to track instance count.
  * `GARBAGE_COLLECTION.java` - Explicit garbage collection using `System.gc()`.
  * `FINALIZE_EXAMPLE.java` - Overriding the `finalize()` method.

* **Encapsulation**
  * `GETTER_AND_SETTER.java` - Data hiding using private fields and public accessors.

## How to Run
1. Open the project folder in IntelliJ IDEA.
2. Navigate to the `src/` directory.
3. Open any `.java` file you wish to run.
4. Click the green "Run" play button next to the `main` method in the editor gutter, or right-click the file and select "Run 'Filename.main()'".
